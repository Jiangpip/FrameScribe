## 它解决什么

看教程最痛苦的两件事：**边看边记要不停暂停**，**看完想回去找某一段找不到**。

FrameScribe 的做法：

| 你做的                            | 它做的                                                |
| ------------------------------ | -------------------------------------------------- |
| 看到重点按 `Alt+S`                  | 截下视频原画、记下时间点，视频不暂停                                 |
| 想补一句按 `Alt+A` 打字，或 `Alt+D` 直接说 | 话记在这张图下面（说的话本机转成文字）                                |
| 没字幕的课按 `Alt+L`                 | 把电脑放出来的声音全程转成文字                                    |
| 看完点「导出并整理」                     | AI 读完截图 + 字幕 + 你的话，写成一篇 Markdown 笔记，每个时间都能点回原视频那一秒 |

一个 YouTube 播放列表几十个视频？点一下「批量大纲」，每个视频一份带时间的章节大纲，外加一份总目录。

## 三步装好

> 只支持 **Windows 10 / 11**，浏览器用 **Chrome 或 Edge**。

**① 下载**：点本页右上角绿色的 **Code → Download ZIP**，解压到一个不会删的地方（比如 `D:\FrameScribe`）。会用 git 的直接 `git clone`。

**② 双击 `setup.cmd`**：它会自动做完这些，每一步都显示结果，可以重复运行：
- 检查 Node.js，没有就问你要不要用 winget 装
- 装软件依赖、下载语音模型（第一次约 650 MB，国内网络会自动换镜像）
- 注册浏览器插件需要的本地桥接，在桌面放一个 FrameScribe 快捷方式

**③ 在浏览器里加载插件**（30 秒，只能手点）：
1. 地址栏打开 `chrome://extensions`（Edge 是 `edge://extensions`）
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选安装目录里的 `extension` 文件夹（setup 已经把路径复制到剪贴板）

然后双击桌面的 **FrameScribe**。第一次打开会有一个欢迎页：确认 AI 引擎、选笔记存到哪（建议填 Obsidian 库里的一个文件夹），就能用了。

> **🤖 懒得自己装？** 把这个仓库的地址发给你的 Claude Code 或 Codex，说一句「**帮我装 FrameScribe**」。仓库里的 [INSTALL_FOR_AI.md](INSTALL_FOR_AI.md) 写好了给 AI 看的安装步骤，它装完会告诉你唯一需要手点的那一步。

## 四种用法

### 1. 看视频随手记（任何视频）

| 快捷键 | 作用 |
|---|---|
| `Alt+S` | 截图 + 记时间点。右上角弹出前 15 秒里的几张候选画面，按慢了也能挑回那张 PPT |
| `Alt+A` | 同上，再写一句；回车保存，Esc 跳过 |
| `Alt+D` | 同上，再说一句；停顿 1.5 秒自动结束，本机转成文字 |
| `Alt+L` | 开始 / 结束听课（见下一节） |

- 在 B 站 / YouTube 网页上（装了插件）：截的是**视频原画**，时间点能点回视频，字幕自动带上。
- 其他地方（本地播放器、网课客户端）：截的是最前面的窗口，时间按电脑时钟记。
- 快捷键和别的软件冲突？在 ⚙ 设置里改。

### 2. 没字幕的课：听课模式

视频在最前面时按 `Alt+L`，托盘图标变红。之后电脑放出来的声音会**在本机**一句一句转成文字（不联网、声音不存盘），想标重点照常按 `Alt+S`。看完再按 `Alt+L`，点「导出并整理」。

### 3. YouTube / 网课回放：大纲 + 点击跳转

打开 YouTube 视频页，右下角点「📒 大纲」：
- 有字幕 → 「取字幕」几秒拿到全文；没字幕 → 「开始转写」静音倍速放一遍、本机转写
- 自动生成**章节大纲**（外语视频的大纲也写中文），点任何一条视频就跳过去；可以搜索全文
- 播放列表页是「📒 批量大纲」：整个列表排队出大纲，再写一份总目录

也支持保利威直播回放页（`*.polyv.cn`），用法相同。

### 4. 随笔：看电影、攒审美素材

顶栏打开「随笔模式」：新记录不带字幕，整理成短随笔，每张图一小节、保留你的原话，AI 只补一两句画面观察。

## 整理用哪个 AI

在 ⚙ 设置 → 整理引擎 里选。第一次启动会自动选本机已有的那个。

| 引擎 | 花谁的钱 | 说明 |
|---|---|---|
| **Claude Code** | 你的 Claude 订阅 | 本机跑 `claude -p`，只给读文件权限，自己看图 |
| **Codex** | 你的 ChatGPT 订阅 | 本机跑 `codex exec`，只读沙箱 |
| **API** | 按量付费 | 预设 DeepSeek、通义、Kimi、智谱、硅基流动、OpenAI、OpenRouter、Claude；也能填本地 Ollama / LM Studio |
| **只导出** | 不花钱 | 只写文件，之后自己整理（附带一个 Claude Code 技能，见 [skills/](skills/)） |

## 导出来是什么样

```
<导出位置>\<视频标题>\
  <视频标题>.md          原始记录：时间点 + 截图 + 你的话 + 附近字幕
  <视频标题>-整理.md     AI 整理版（时间可点）
  <视频标题>-大纲.md     章节大纲（YouTube / 回放）
  字幕.md · raw.json · img\
```

直接放进 Obsidian 库就能用；时间链接点开会跳到视频那一秒。

## 常见问题

<details><summary><b>setup.cmd 一闪而过 / 报错</b></summary>

右键 setup.cmd →「在终端中打开」看完整输出；或运行 `setup.cmd -Check` 只做检查。最常见是 Node.js 没装好：装完 [Node.js LTS](https://nodejs.org) 后**重新打开**窗口再运行。
</details>

<details><summary><b>笔记本右上角一直是「插件未连接」</b></summary>

确认插件已加载、软件开着，再打开一个 B 站或 YouTube 视频页，几秒内就会连上。不装插件也能用，只是截的是屏幕。
</details>

<details><summary><b>按快捷键没反应</b></summary>

被别的程序占用了（比如微信截图默认 `Alt+A`）。⚙ 设置 → 快捷键 会显示哪个没注册上，换一个组合。
</details>

<details><summary><b>整理失败：「本机没找到 Claude Code」</b></summary>

在命令行里能运行 `claude` 或 `codex` 吗？不能就先装好并登录一次。都不想装就选 API 填 Key。失败时状态条上的「看日志」能看到原因。
</details>

<details><summary><b>转写有错字</b></summary>

本机模型（SenseVoice）会有同音错字，专有名词尤其容易错。整理时 AI 会按上下文改正，拿不准的放进「待查」。
</details>

<details><summary><b>截出来是黑的</b></summary>

有版权加密的播放器（部分付费影视）截不了，这是浏览器的保护，软件不绕过。
</details>

## 隐私

- 截图、录音、转写、笔记都存在你自己电脑上（`%APPDATA%\FrameScribe` 和你选的导出位置）。
- 语音转写在本机 CPU 上跑，不联网；听课模式的声音不存盘，只留文字。
- 只有你点「整理」时，材料才会交给你选的 AI（Claude Code / Codex / 你填的 API）。
