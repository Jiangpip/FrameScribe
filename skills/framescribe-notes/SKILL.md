# 整理 FrameScribe 视频笔记

安装：把本文件夹复制到 `~/.claude/skills/framescribe-notes/`（或项目的 `.claude/skills/` 下）。
用法：FrameScribe 里选「只导出」后，在 Claude Code 里说 `/framescribe-notes D:\笔记\视频笔记\<视频标题>`。

导出文件夹里有：

- `<视频文件夹>.md`：原始记录（按键时间点 + 截图 + 用户随手写的一句 + 附近字幕），**只读**
- `raw.json`：同样内容的结构化版本，`subtitles.body` 是完整字幕（`from`/`to` 秒 + `text`），`subtitles.status` 为 `ok` / `none` / `need_login` / `error`
- `字幕.md`：完整字幕，约 30 秒一段，带可点时间
- `img/`：用户挑定的截图

## 步骤

1. **找到文件夹**。参数是绝对路径就直接用；只给了文件夹名就问用户导出位置在哪，再用 Glob 搜 `**/<视频文件夹>/raw.json`。
2. **读全**：`raw.json`、`字幕.md`，并用 Read 逐张看 `img/` 里的图。截图里常有 PPT、公式、代码、图表，字幕里没有，要从图里读出来。
3. **写** `<视频文件夹>-整理.md` 到同一文件夹。不改原始 md、raw.json 和图片。已有整理版时先问用户是覆盖还是另存。

## 整理版结构

```markdown
---
来源: <视频链接>
UP主: ...
原始记录: "[[<视频文件夹>]]"
整理于: YYYY-MM-DD
tags: [视频笔记]
---
# <标题>

> 一段话：这个视频讲了什么、主要结论是什么（3–5 句）

## 1. <主题>
- 要点……关键概念加粗
![](img/xxx.jpg)
*图：这张图在说明什么* · [mm:ss](带时间的链接)

> [!note] 我的笔记
> 用户原话，一字不改

## 待查
- 字幕可能识别错的专有名词、讲者没讲清楚的地方
```

## 规则

- 按**内容主题**分节，不按记录点机械罗列；每张用户截的图都要用上，放在讲到它的位置。
- 用户自己写的笔记保留原话，放在相关小节的 `[!note] 我的笔记` 里，这是用户认为重要的地方，讲透一点。
- 图里的公式写成 LaTeX，代码写成代码块，表格转成 Markdown 表。
- 只写视频里讲了的内容；补充背景知识要标“（补充）”。
- 字幕常错专有名词：对照画面纠正，拿不准的放进“待查”。
- 没有字幕（status 不是 ok）：只依据截图和用户笔记整理，开头写明“本视频没有拿到字幕，内容只来自截图和笔记”。
- 结尾只写事实或判断，不写煽情的收尾。
- 写完回复整理版的完整绝对路径。
