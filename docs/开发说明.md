# 开发说明

## 两部分怎么配合

| | 桌面软件 `app\` | 浏览器插件 `extension\` |
|---|---|---|
| 管什么 | 全局快捷键、弹窗、录音转写、笔记本、导出、整理、大纲队列 | B 站网页的视频原画、精确时间点、字幕；YouTube / 回放页的大纲面板、取字幕 / 转写、点击跳转 |
| 单独用 | 可以：截最前面的窗口，时间按电脑时钟，没有字幕 | 可以（只限 B 站）：插件自己的快捷键和笔记本，导出 / 整理走本地桥接 `host\` |

两个都开着时，按键由软件接管：最前面的窗口是装了插件的视频页就用插件的原画，否则截屏。插件经 WebSocket `127.0.0.1:38917` 连软件，软件只接受 `host\EXTENSION_ID.txt` 里的扩展 ID（由 `extension\manifest.json` 的 `key` 固定，所有人加载出来都是同一个 ID）。

## 代码结构

```
app\                     桌面软件（Electron）
  main.js                快捷键、截图流程、插件连接、托盘、界面请求、首次启动引导、旧数据目录迁移
  store.js               记录存成文件（%APPDATA%\FrameScribe\data）
  organize.js            导出 + 整理 + 生成大纲 / 总目录（API 调用在这里；CLI 引擎用 host\core.js）
  asr-worker.js          语音转写进程（sherpa-onnx + SenseVoice；听课时先用 silero VAD 按停顿分句）
                         可单独测：node asr-worker.js 某个16k.wav [--stream]；BN_ASR_MODEL_DIR 可指向别的模型
  win32.js               读最前面的窗口：标题、程序名、位置（koffi）
  preload.js             界面和主程序之间的消息口
  ui\capture.*           看不见的窗口：每块屏幕每秒存一张，只留 15 秒，只在内存里；听课时在这里录系统声音
  ui\overlay.*           右上角弹窗；录音在这里做
  ui\notebook.*          笔记本窗口（含设置和欢迎引导）
  models\                语音模型（setup 下载，不进仓库）
extension\               浏览器插件（MV3）
  content.js             B 站页：回看缓冲、截原画、取字幕
  page-main.js           YouTube / 回放页，跑在页面自己的环境里：找播放器、接出声音、后台不降速、取字幕
  panel.js               大纲面板：取字幕 / 转写、大纲 / 搜索 / 跳转、截画面、播放列表批量
  background.js          插件自己的快捷键和数据库；连软件；桥接；各家 API
  manager.*              插件自己的笔记本页（软件没开时用）
  lib\note.js            导出文件格式（软件也用这一份）
  lib\prompt.js          整理 / 大纲提示词（软件也用这一份）
host\
  core.js                找引擎（常见位置 + PATH，解析 npm 的 .cmd 外壳）、调 Claude Code / Codex
  host.js                桥接程序（Native Messaging），只在“只用插件”时需要
  install-host.ps1       注册桥接到 Chrome / Edge / Chromium（HKCU）
scripts\
  setup.ps1              一键安装 / 检查（setup.cmd 调它）
  check-privacy.ps1      提交前的隐私检查
skills\framescribe-notes Claude Code 手动整理技能
```

## 语音模型

- `sense-voice\model.int8.onnx` + `tokens.txt`：SenseVoice 2024-07-17 int8 版（Hugging Face `csukuangfj/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17`）。2025-09 版是粤语微调，普通话不准；funasr-nano-int8-2025-12 比过，错字差不多还没标点。
- `silero_vad.onnx`：sherpa-onnx `asr-models` 发布里的那一版（setup 按 SHA256 校验）。

## 调试与测试

- 环境变量：`BN_DEBUG=1` 打开调试口（只在 127.0.0.1）；`BN_DATA=<目录>` 数据放到别处；`BN_PORT=<端口>` 换端口；`BN_ASR_LANG` 固定转写语言。
- 调试口 `http://127.0.0.1:<端口>/debug/…`：`hotkey`（触发快捷键）、`shot`（截窗口图）、`voice`（塞一段 wav 当录音）、`state`、`eval`、`quit`。`eval` 能执行任意代码，只在调试时开。
- 测试实例：`BN_DEBUG=1 BN_PORT=38918 BN_DATA=<临时目录>` 启动 `app\node_modules\electron\dist\electron.exe app --hidden`，快捷键在设置里改成冷门组合，别和正在用的实例抢。
- 测插件：用全新的浏览器 user-data-dir 加载一份改了端口的插件拷贝；加 `--mute-audio`。

## 已知限制

- 屏幕记录不开听课就没有文字；时间点不能点回视频。
- 听课不会自动截图：画面上展示、嘴上没说的内容要自己按键。
- 屏幕记录截的是“最前面的窗口”或整个屏幕，还不能框选区域。
- B 站课堂（`/cheese/`）页面插件还不支持，会当成屏幕记录。
- 有版权加密的播放内容截不了，软件不绕过。
- 转写有同音错字；更准要上 Whisper large-v3 这一档（未做）。

## 日志

- 软件：`%APPDATA%\FrameScribe\app.log`
- 整理 / 大纲：安装目录 `host\logs\`（失败时状态条的「看日志」直接打开）
- 截屏全黑：锁屏 / 休眠后系统会断掉截屏用的画面流，软件会自动重开（日志里有「画面断了 → 重新打开」）。

## 改名说明

0.9.0 起名字从 BiliNotes 改为 FrameScribe。旧的数据目录 `%APPDATA%\BiliNotes` 会在第一次启动时自动改名迁移；插件内部的数据库名、存储键、时间参数 `bn_t` 保持不变，旧笔记里的链接照常能跳。
